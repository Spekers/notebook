## sidenote
@sidenote: text
Numbered footnote-style. A small superscript number appears inline; the note sits in the margin on desktop. On mobile the number becomes a tap target that toggles the note open. Most common — use this by default.


@marginnote: text
Same as @sidenote but with a ⊕ symbol instead of a number, and no auto-numbering. Use when the note isn't sequential — e.g. a citation, an aside not part of the main flow.


@marginnote-mobilehide: text
A margin note that's visible on desktop and completely hidden on mobile. There's no toggle marker — readers on a phone simply won't see it. Use for purely decorative asides where mobile readers wouldn't miss anything.


@marginnote-mobileshow: text
A margin note that's always shown, on both desktop and mobile, with no toggle. (The checkbox is rendered pre-checked, which forces the note open.) Use when the aside is essential context and you want it visible inline on mobile rather than hidden behind a tap.

## steps
1. run ./bin/author/blank.sh name, to create a new entry
2. write
3. run ./bin/serve.sh, to build
4. ./bin/deploy.sh --pages, to deploy

to rerun : lsof -ti :8000 | xargs kill && rm -rf out && ./bin/serve.sh
to kill localhost : lsof -ti :8000 | xargs kill
