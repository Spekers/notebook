# Cave Diver Techno

## Description

This mix came from me discovering "Loidis - The Floating World (& All Its Pleasures)". The repetitive nature gives it an almost meditative quality. I'd put this kind of ambient-techno on to do chores or as background focus music. It took a while before I was able to find words/genre-name to find similar stuff. If you've got any recommendations, leave them below!
